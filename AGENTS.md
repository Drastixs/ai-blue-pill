# AI bluepill
A project which wraps a custom harness over `codex` and `claude` ai harnesses to improve prompting and detect and monitor what tool calls are actually doing. This is a overwatch tool that can provide prompts to these harnesses (headed) and monitor the tool requests and responses using a judge llms to detect any issues.


## Who is Who
- Developers - the developers that are currently helping you build this project 
- Users - the users that are using this product to bench mark ai sessions (only refer to them as this not customers)
- Parent - The overwatching coding harness (typically a `pi` instance)
- Child - the target ai harness (either `codex` or `claude`)
- You - the agent reading this text and file
